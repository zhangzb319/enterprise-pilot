## 踩坑记录（重要）

- 该项目是 **Spring Boot 4.0.7 + Spring 7 + Jackson 3**：JSON 类型是 `tools.jackson.databind.ObjectMapper`，**不是** `com.fasterxml.jackson.databind.ObjectMapper`；注入 Jackson 2 的 Mapper 会导致容器里找不到 Bean、启动失败。
- GLM `stream=True` 时忽略 `tools`（已实测），所以"流式 + 工具调用"单次完成不可行，必须两段式。
- 用 javac 直连 m2 时必须按 artifact 去重并让 pom 锁定版本优先，否则会取到 jjwt 0.9.1（同名 `JwtBuilder`）和 spring-security 6.x；jsqlparser 需固定 4.6（4.9 删了 `SelectBody`，pagehelper 5.3.3 依赖它）。
- MySQL CLI 输出中文需加 `--default-character-set=utf8mb4`，否则 Git Bash 里显示 "Binary file matches"。
